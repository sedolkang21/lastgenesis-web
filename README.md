# Last Genesis — web build for ONE store

The web build of *Last Genesis* (인류의 마지막 창세기) for ONE store's web game shelf, served by GitHub Pages. ONE store's app opens `index.html` in a frame; outside it the game runs as the trial and purchases are not available.

Game files only (Godot 4.7 web export). The source is kept privately. Licences of the engine, fonts, music and sound effects are in `licenses/` and in the game (title → 라이선스 / Licences).
